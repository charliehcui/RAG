# RAG# RAG

A learning-focused project for building and understanding Retrieval-Augmented Generation (RAG) systems.

## Project Goal

This project focuses on the core RAG workflow:

1. Load documents
2. Split documents into chunks
3. Generate embeddings
4. Store embeddings in a vector database
5. Retrieve relevant documents based on user queries
6. Use an LLM to generate answers with retrieved context

## Tech Stack

- Python
- LangChain
- Vector Database
- Large Language Models (LLMs)

## Focus

The main focus of this project is RAG development, including document retrieval, embeddings, vector search, and LLM-based question answering.
